## Secure File Downloads
- Implemented secure file download endpoints for photos, signatures, and PDFs:
  - `GET /api/v1/files/photos/{photo_id}` - Download photo by ID
  - `GET /api/v1/files/signatures/{signature_id}` - Download signature image
  - `GET /api/v1/files/pdfs/{ticket_id}` - Download ticket PDF
- Created `FileService` with company-scoped queries:
  - Joins through `tickets` table to enforce multi-tenancy
  - Returns 404 for unauthorized access (prevents information leakage)
- File serving implementation:
  - Sets correct `Content-Type` from stored MIME type or file extension
  - `ETag` header from SHA-256 file hash for caching
  - `Cache-Control: private, max-age=3600` for authenticated responses
  - `Content-Disposition: attachment` for PDF downloads
  - Conditional requests with `If-None-Match` return 304 Not Modified
- Security features:
  - Path traversal protection via absolute path prefix validation
  - Storage base configuration required (returns 500 if not set)
- Handler tests cover:
  - Not found, cross-company denied, invalid UUID
  - Unauthenticated access, successful download
  - Conditional requests, path traversal prevention
  - Storage not configured error
- `make build` and `make test` pass

## Immutable Photo Caching
- Implemented long-lived immutable caching for photo downloads:
  - Photos served via `/api/v1/files/photos/{photo_id}` are inherently immutable (unique ID per upload)
  - Updated `serveFile()` in `internal/handler/file.go` to accept `isImmutablePhoto` flag
  - Photo responses now use `Cache-Control: private, max-age=31536000, immutable` (1-year cache)
  - Signatures and PDFs retain shorter `max-age=3600` cache since they may be regenerated
- Auth checks remain enforced:
  - `private` directive prevents shared caching
  - Auth middleware runs on every request before file serving
  - ETag from SHA-256 hash enables conditional requests (304 Not Modified)
- Added new handler tests:
  - `TestFileHandlerDownloadSignatureSuccess` - verifies signature caching and headers
  - `TestFileHandlerDownloadPDFSuccess` - verifies PDF caching, headers, and Content-Disposition
  - Updated `TestFileHandlerDownloadPhotoSuccess` to verify immutable cache header
- `make build` and `make test` pass
